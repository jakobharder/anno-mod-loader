    Basic ModOp Types¶

    Replace¶

    Replaces the selection.

    <ModOp GUID="123" Replace="Standard/Name">
  <Name>new name</Name>
</ModOp>

    <ModOp Replace="@123/Standard/Name">
  <Name>new name</Name>
</ModOp>

    <ModOp GUID="123" Type="replace" Path="/Values/Standard">
  <Name>new name</Name>
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
-     <Name>old name</Name>
+     <Name>new name</Name>
    </Standard>
  </Values>
</Asset>

    Replace is not limited to single elements. Elements containing elements can be replaced as well.

    <ModOp GUID="123" Replace="Standard">
  <Standard>
    <GUID>456</GUID>
    <Description>description</Description>
  </Standard>
</ModOp>

    <ModOp Replace="@123/Standard">
  <Standard>
    <GUID>456</GUID>
    <Description>description</Description>
  </Standard>
</ModOp>

    <ModOp GUID="123" Type="replace" Path="/Values/Standard">
  <Standard>
    <GUID>456</GUID>
    <Description>description</Description>
  </Standard>
</ModOp>

    <Asset>
  <Values>
    <Standard>
-     <GUID>123</GUID>
-     <Name>name</Name>
+     <GUID>456</GUID>
+     <Description>description</Description>
    </Standard>
  </Values>
</Asset>
    An empty replace is the same as remove. 
    <ModOp Replace="@123/Cost" />

    Applies to all versions.

    <ModOp Remove="@123/Cost" />

    Applies to all versions.

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
    </Standard>
-   <Cost />
  </Values>
</Asset>

    Add¶

    Adds the content at the end inside of the selection.

    <ModOp GUID="123" Add="">
  <Maintenance />
</ModOp>

    <ModOp Add="@123">
  <Maintenance />
</ModOp>

    <ModOp GUID="123" Type="add" Path="/Values">
  <Maintenance />
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
    </Standard>
+   <Maintenance />
  </Values>
</Asset>

    Add does not check if an element already exists. Use Merge or Conditions for that purpose.

    Merge¶

    Adds the content, or replaces it if it already exists.

    <ModOp GUID="123" Merge="Standard">
  <Standard>
    <Name>new name</Name>
    <Description>desc</Description>
  </Standard>
</ModOp>

    <ModOp Merge="@123/Standard">
  <Standard>
    <Name>new name</Name>
    <Description>desc</Description>
  </Standard>
</ModOp>

    <ModOp GUID="123" Type="merge" Path="/Values/Standard">
  <Standard>
    <Name>new name</Name>
    <Description>desc</Description>
  </Standard>
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
-     <Name>old name</Name>
+     <Name>new name</Name>
+     <Description>desc</Description>
    </Standard>
  </Values>
</Asset>
    You may leave out the top-level element (here Standard) in most situations

    The following is shorter and has to the same result.

    <ModOp Merge="@123/Standard">
  <Name>new name</Name>
  <Description>desc</Description>
</ModOp>

    <ModOp GUID="123" Type="merge" Path="/Values/Standard">
  <Name>new name</Name>
  <Description>desc</Description>
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
-     <Name>old name</Name>
+     <Name>new name</Name>
+     <Description>desc</Description>
    </Standard>
  </Values>
</Asset>

    Only when the selected element has a child with the same name, you must use the long way. In doubt, always use the long way.

      <Text>
    <LineId>123</LineId>
    <Text>old text</Text>
  </Text>

    <ModOp Merge="@123/Text">
  <Text>
    <Text>new text</Text>
  </Text>
</ModOp>

    <ModOp GUID="123" Type="Merge" Path="/Values/Text">
  <Text>
    <Text>new text</Text>
  </Text>
</ModOp>

    <Text>
  <LineId>123</LineId>
-   <Text>old text</Text>
+   <Text>new text</Text>
</Text>

    Append¶

    Adds the content after the selection.

    <ModOp GUID="123" Append="Standard">
  <Maintenance />
</ModOp>

    <ModOp Append="@123/Standard">
  <Maintenance />
</ModOp>

    <ModOp GUID="123" Type="addNextSibling" Path="/Values/Standard">
  <Maintenance />
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
    </Standard>
+   <Maintenance />
    <Cost />
  </Values>
</Asset>

    A common situation is when you want to insert an item at a specific position.

    <ModOp GUID="123"
       Append="ConstructionCategory/BuildingList/Item[Building='1000178']">
  <Item>
    <Building>123</Building>
  </Item>
</ModOp>

    <ModOp Append="@123/ConstructionCategory/BuildingList/Item[Building='1000178']">
  <Item>
    <Building>123</Building>
  </Item>
</ModOp>

    <ModOp GUID="123" Type="addNextSibling"
       Path="/Values/ConstructionCategory/BuildingList/Item[Building='1000178']">
  <Item>
    <Building>123</Building>
  </Item>
</ModOp>

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
    </Standard>
    <ConstructionCategory>
      <BuildingList>
        <Item>
          <Building>1000178</Building>
        </Item>
+       <Item>
+         <Building>123</Building>
+       </Item>
        <Item>
          <Building>1010372</Building>
        </Item>
      </BuildingList>
    </ConstructionCategory>
  </Values>
</Asset>

    Prepend¶

    Prepend works the same as Append except that it adds the content before the selection.

    <ModOp GUID="123" Prepend="Standard">
  <Maintenance />
</ModOp>

    <ModOp Prepend="@123/Standard">
  <Maintenance />
</ModOp>

    <ModOp GUID="123" Type="addPrevSibling" Path="/Values/Standard">
  <Maintenance />
</ModOp>

    <Asset>
  <Values>
+   <Maintenance />
    <Standard>
      <GUID>123</GUID>
    </Standard>
    <Cost />
  </Values>
</Asset>

    Remove¶

    Removes the selected elements.

    <ModOp GUID="123" Remove="Cost" />

    <ModOp Remove="@123/Cost" />

    <ModOp GUID="123" Type="remove" Path="/Values/Cost" />

    <Asset>
  <Values>
    <Standard>
      <GUID>123</GUID>
    </Standard>
-   <Cost />
  </Values>
</Asset>

    Removing an not existing element leads to warning

    As with all ModOps, there will be a warning if the selected element path does not exist.
