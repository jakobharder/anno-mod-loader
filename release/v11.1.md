XML test tools for Anno 1800 and Anno 117.

Download and extract **xmltest.zip** (Windows x64):

- **xmltest1800.exe**: the existing Anno 1800 `xmltest.exe`, preserved byte for byte and renamed.
- **xmltest117.exe**: the Anno 117 v3.0 implementation, previously named `xmltest2.exe`.

The Anno 117 loader code and dependency revisions are taken from the merge of [PR #20](https://github.com/jakobharder/anno-mod-loader/pull/20), commit `9b31c2e699e922f0befb9355877866bba5f29348`. Later FileDB and ModValue changes for future game versions are excluded.

`xmltest117.exe --version` reports `Anno 117 v3.0`. Release `v11.1` identifies this distribution; the game implementation version is separate.

The archive includes the license and a provenance manifest with executable checksums. A separate `xmltest.zip.sha256` file verifies the download.
